1.What is CSS? What are the different ways to apply CSS?
=> CSS (Cascading Style Sheets) is used to style and design HTML web pages.
   there are 3 ways to apply css:
   1.inline css
   2.internal css
   3.external css




2.Inline, Internal, and External CSS.
=> 1.inline css - Used for applying a style to one specific elements
   <h1 style="color: red;">Welcome</h1>
   
   2.internal css - Used when CSS is specific to one HTML page.
    <style>
    h1 {
        color: blue;
    }
    </style>
   
   3.external css - Used when styles need to be shared across multiple pages.
   <link rel="stylesheet" href="style.css">
   h1{
    color:"red";
   }





3.What is the CSS Box Model?

4.Content → Padding → Border → Margin.

Border = line around padding/content
Margin = space outside the border






5.What is the difference between margin and padding?
=>Padding is the space inside an element.
 Margin is the space outside an element.

Absolute

13.display: flex, flex-direction, justify-content, align-items, flex-wrap, etc.
=>display: flex
Turns an element into a flex container.

flex-direction
Controls the main direction.

justify-content
Controls alignment along the main axis.

align-items
Controls alignment along the cross axis.

flex-wrap
Controls whether items can move onto multiple lines.

gap
Adds space between flex items.
