4.What is the difference between <div> and <span>?
=> <div> is a Block-level element ,Usually starts on a new line,Used for larger sections.
  <span> is a Inline element,it Stays in the same line, Used for small pieces of content

5.What is the difference between block-level and inline elements?
=> Block-level elements normally take the full available width and start on a new line
   example : <div>
    Inline elements take only the space they need and don't normally start a new line.
    example : <span>

=> <!DOCTYPE html> tells the browser that the document uses HTML5.
    It should be placed at the very beginning of an HTML document.
    It helps the browser render the page.
